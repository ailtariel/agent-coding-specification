# Interface Design

Start from the user's workflow, existing design system, product constraints, and supplied artifacts. Use the user's chosen tool or the project's native representation. Inspect existing tokens and comparable screens before asking for information already available.

Make routine reversible design choices within the goal. Ask only when a missing decision materially changes the outcome. Deliver the requested design or review; ordinary UI work does not require a separate design document unless requested or required for material business decisions.

Check the affected flow's hierarchy, responsive behavior, feedback states, keyboard access, and consistency. State what was actually inspected; a screenshot does not prove all interactions or numerical contrast ratios.
