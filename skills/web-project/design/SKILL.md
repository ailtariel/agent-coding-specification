# Penpot Design

Use available Penpot MCP tools to inspect the target document, discover existing components/tokens, make the requested changes, and export relevant views for visual verification. General UI/UX work does not imply choosing Penpot.

Discover available tools before invoking them. If the connection fails, inspect the specific failure and perform authorized read-only diagnostics; ask only for missing information or access that blocks the task. Setup is a separate workflow, not a prerequisite for general design advice. Do not install a server merely because a design task mentions forms or layouts.

Preserve the target's design system. Infer routine details from the file and user request; ask only when a consequential requirement cannot be inferred. Check existing boards and place new boards without overlaps. Verify the changed areas, not every component in the file.
